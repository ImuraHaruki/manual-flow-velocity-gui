# 手動流速測定 GUI

連続画像の2コマを比較し、画像上で指定した粒子の1次元速度を手動測定する
Windows向け試作版です。

## Windows版（推奨）

GitHub Releasesから `ManualFlowVelocity-v1.0.0-win64.zip` をダウンロードし、
展開後に `ManualFlowVelocity.exe` をダブルクリックしてください。Pythonやcondaは
不要です。Windows SmartScreenが表示された場合は、ファイルの入手元を確認した上で
「詳細情報」から実行できます。

## 起動

`起動.bat` をダブルクリックしてください。GUI専用のconda環境
`flow-velocity-gui` が自動的に使用されるため、事前の `conda activate` は不要です。

初期設定画面で次を指定します。

- 連続画像が入ったフォルダ
- フレームレート（サンプル画像では `240` fps）
- 長さの単位（初期値 `cm`）

## 測定手順

1. 画面上部の「校正長さ」に、基準となる実際の長さを入力します。
2. before画像で、その長さに対応する2点を順にクリックします。
3. 点1から点2へ向かう方向が、速度の正方向になります。
4. before画像とafter画像で、同じ粒子を1回ずつクリックします。
5. 表示された移動量と速度を確認し、「記録して次へ」を押します。
   同じ画像ペアで別の粒子も測る場合は「同じペアに追加記録」を押します。
6. after画像が次のbefore画像になります。前回のafter側の粒子位置も
   新しいbefore側へ引き継がれるため、通常は次のafter側だけをクリックできます。
   適切な粒子がない画像ペアは「測定せず次へ（スキップ）」で結果を残さず進めます。
7. 測定後、CSVまたはグラフ画像を出力します。

## CSVの再読込

「CSV読込」から、このソフトで出力した測定結果CSVを読み込めます。CSV内の
before／after画像ファイル名を現在の画像フォルダと照合して結果を復元します。
既存結果がある場合は、置き換えまたは追加を選択できます。

上下方向を単純に捨てるのではなく、粒子の移動ベクトルを校正線へ投影し、
校正線に沿った成分だけを使って速度を計算します。

## 画面操作

- 左クリック: 校正点または粒子位置の指定
- マウスホイール: カーソル位置を中心に拡大・縮小
- 右ボタンまたは中ボタンのドラッグ: 表示位置の移動
- `Enter`: 記録して次へ
- `Esc`: 現在の指定をクリア
- `Ctrl+S`: CSV出力
- `Ctrl+A`: 測定結果をすべて選択
- `←`: 前の画像ペアへ戻る
- `→`: 測定結果を記録せず次の画像ペアへ進む

左右矢印キーは押し続けると連続移動できます。校正長さやfpsなどの入力欄を
編集中は、数値編集を優先するため画像移動には使われません。

「after画像にbefore位置を表示」をオンにすると、before画像で指定した粒子座標を
after画像上へ紫色の十字マーカー「before位置（参考）」として表示します。
不要な場合はチェックを外すと非表示になります。この参考マーカーは測定座標には
使われません。

結果表は `Ctrl` または `Shift` を押しながらクリックすると複数行を選択できます。
「測定結果をすべてクリア」では、確認後に表の全結果を消去できます。
結果の行をダブルクリックするか、「選択行の画像へ移動」を押すと、その測定に
使ったbefore／after画像と粒子位置を再表示できます。
「前の画像ペア」で戻った場合も、そのペアに保存済みの粒子位置を黄色の
「記録No.」マーカーで表示します。複数の測定がある場合はすべて表示します。

校正長さ、校正点、フレームレート、単位を変更すると、記録済みのクリック座標を
使ってすべての測定結果が自動的に再計算されます。

## 計算

校正線の単位方向ベクトルを `u`、画像上の粒子移動を `d`、
校正線のピクセル長を `Lpx`、入力した実長を `L` とすると、

```
1次元移動量 = (d・u) × L / Lpx
時間間隔   = コマ間隔 / fps
速度       = 1次元移動量 / 時間間隔
```

速度は符号付きです。

## conda環境

このPCには次の専用環境を作成済みです。

```
C:\Users\haruh\anaconda3\envs\flow-velocity-gui
```

別のPCで環境を作り直す場合は、Anaconda Promptでこのフォルダへ移動し、
次を実行します。

```
conda env create -f environment.yml
```

## 必要環境

- Windows
- Anaconda
- 専用conda環境 `flow-velocity-gui`

## 開発・リリースビルド

専用conda環境を作成後、PowerShellで次を実行すると単体EXEと配布ZIPを生成します。

```powershell
.\build_release.ps1
```

`v1.0.0`のようなタグをGitHubへpushすると、GitHub ActionsでもテストとWindows版の
ビルドを行い、ZIPをGitHub Releaseへ自動添付します。
